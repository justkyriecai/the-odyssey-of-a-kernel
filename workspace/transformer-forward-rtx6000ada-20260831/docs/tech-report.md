# Tech Report

The submission tech report lives with the campaign that produced its
numbers:
[`workspace/transformer-forward-opt/docs/tech-report.md`](../../transformer-forward-opt/docs/tech-report.md).

This workspace was branched with an empty ledger, and a number is only a
number if this workspace measured it -- so the report stays next to the
`runs/` that back every figure in it. If a campaign here produces its own
results, it writes its own report against this directory's ledger.
